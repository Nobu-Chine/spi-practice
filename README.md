# SPI非言語 練習アプリ

転職の適性検査（SPI）の非言語分野を、スマホでもPCでもすきま時間に練習できるWebアプリです。

**公開ページ：** https://spi-practice-app.vercel.app

## できること

- **7分野から選んで練習**：割合・損益算・速度算・集合・場合の数・確率・推論、または「全分野ミックス」（各分野から均等に出題）
- **1回10問・4択・1問60秒**：タイマーが0になると時間切れ（不正解あつかい）
- **答えるとすぐに正誤と解説**：解説は計算の手順を1行ずつ表示。集合は人数の表で全体像を見せてから式で答えを出す
- **間違えた理由がわかる**：選んだ誤答が「どの計算ミスで出る数字か」を表示（例：「増えた後の人数から%を引いてしまった」）
- **AIに質問用にコピー**：解説を読んでもわからないときは、ボタン1つで「分野・問題・選択肢・自分の答え・正解・解説」をまとめてコピー。ChatGPT や Claude などに貼り付けて、続けて質問を書くだけで聞ける
- **結果画面**：正答率、分野別の正答率、解答にかかった時間
- **間違えた問題の復習**：間違えた問題・時間切れの問題は自動で「復習リスト」に入り、トップ画面の「間違えた問題を復習」から解き直せる。正解したらリストから消える。選択肢の並びは毎回入れ替わるので、正解の位置では覚えられない
- **成績の記録と苦手分野**：成績はブラウザに保存され、直近の正答率がいちばん低い分野に「苦手」と表示（復習の回は同じ問題の解き直しなので、成績には入れない）

問題は固定の問題集ではなく、テンプレートと乱数から毎回自動で作るので、何度解いても同じ問題になりにくくなっています。

## 使い方

1. 公開ページを開く
2. 練習したい分野（または全分野ミックス）を選ぶ
3. 4つの選択肢から答えを選ぶ → 正誤と解説を読んで「次の問題へ」
4. 10問解くと結果が出る。トップ画面に戻ると、これまでの成績と苦手分野が見られる

### 自分のPCで動かす場合

ビルド（変換作業）は不要です。Node.js が入っていれば、次のコマンドでサーバーを起動して `http://localhost:3000` を開きます。

```bash
npx serve . -l 3000
```

※ ファイル同士を読み込み合う仕組み（ES modules）を使っているため、`index.html` をダブルクリックで開くだけでは動きません。

問題の自動チェック（後述）は次のコマンドで実行できます。

```bash
node tests/check.js
```

## 工夫した点

### 1. 役割ごとのファイル分け

1つのファイルに処理を詰め込まず、「表示」「進行」「問題づくり」「保存」を別々のファイルに分けました。画面側は進行役を呼び出して、返ってきた結果を表示するだけで、計算や採点は一切しません。

```
js/
├─ main.js            部品同士をつなぐだけ
├─ config.js          設定（問題数・制限時間・電卓あり/なし）
├─ ui/
│  ├─ view.js         表示とボタン操作だけ
│  └─ clipboard.js    クリップボードへのコピー（iPhone向けの予備の方法つき）
├─ core/
│  ├─ quiz.js         出題・採点・結果のまとめ
│  ├─ timer.js        制限時間（終了予定時刻との差で数えるので、スマホで画面を切り替えてもずれない）
│  ├─ choices.js      4択の組み立て
│  ├─ stats.js        正答率・苦手分野の集計
│  ├─ mistake-book.js 復習リストの決まり（同じ問題は1回だけ・最大100問・古い順に出す）
│  ├─ ask-text.js     「AIに質問用にコピー」の文章づくり
│  ├─ format.js       数字や解説の書き方（画面・コピー文・チェックで共通）
│  └─ values.js       答えの値（整数と、確率の分数）の比べ方・判定
├─ generators/        問題づくり（分野ごとに1ファイル）
│  ├─ index.js        分野の登録簿
│  ├─ ratio.js        割合
│  ├─ profit.js       損益算
│  ├─ speed.js        速度算
│  ├─ sets.js         集合
│  ├─ counting.js     場合の数
│  ├─ probability.js  確率
│  └─ reasoning.js    推論（順位・内訳・位置）
└─ storage/
   ├─ history.js      成績の保存と読み込みだけ
   └─ mistakes.js     復習リストの保存と読み込みだけ
```

分野を増やすときは、`generators/` にファイルを1つ作り、登録簿（`generators/index.js`）に1行足すだけで済みます。画面や進行役のコードは触りません。

### 2. 答えの自動チェック

問題を自動で作る以上、「答えが本当に正しいか」を人の目だけで確かめるのは不可能です。そこで次の2つの仕組みを入れました。

- **逆算で作る**：先にきれいな答えを決めてから、問題に出す数字を計算します（例：全体を300人と決めてから「20%が60人」を作る）。これで割り切れない答えが構造的に出ません。
- **別の道で解き直す**：各テンプレートは、問題文に出した数字だけを使って順方向に解き直す「検算」を持っています。作る道と確かめる道が別なので、式の書き間違いが見つかります。場合の数と確率では、公式を使わずに全部の並べ方・選び方・さいころの目の出方を1つずつ数え上げて確かめています。推論では、考えられる並び方（5人なら120通り）や内訳を全部たどって、推論ア・イ・ウが「どれでも成り立つか」を確かめています。

`tests/check.js` は、全テンプレートを「電卓なし」「電卓あり」でそれぞれ1000問ずつ作り、次のことを確かめます。

- 答えが正の整数（確率は0と1の間の約分済みの分数）で、検算の結果と一致する
- 選択肢が4つで、重複がなく、正解がちょうど1つ
- 補充した選択肢が正解から離れすぎていない（整数は±10%以内）
- 問題文や解説に `NaN` などの崩れがない
- 解説の表で強調しているマスが答えと一致する
- 分野ごとのルール（例：損益算で赤字の組み合わせを使っていない、集合の人数がどれも1人以上）

おかしな問題が見つかったときは、その問題の乱数の種（seed）が表示され、同じ問題を再現して直せます。

さらに、チェックそのものが甘くなっていないかも確かめています。`tests/check-selftest.js` が、正常な問題を1か所ずつわざと壊し（選択肢の重複・検算と合わない答え・約分されていない分数など20通り）、すべて NG として見つけられるかを毎回最初に試します。

### 3. よくあるミスから作る選択肢

不正解の選択肢はランダムな数ではなく、SPIでよくある計算ミスから作っています。

| 分野 | ミスの例 |
|---|---|
| 割合 | 「去年より25%増えて150人」の去年を、150人から25%引いて求めてしまう |
| 損益算 | 「30%増しの定価から10%引き」を、単純に20%増しと考えてしまう |
| 速度算 | 行きと帰りの速さを足して2で割り、平均の速さにしてしまう |
| 集合 | 合計からAとBを引くだけで、両方の人を2回引いてしまう |

ミスの答えが割り切れない数になると選択肢に使えないため、問題の数字を選ぶ段階で「代表的なミスの答えも整数になる数字」を優先しています。選んだ誤答にはミスの説明が表示されるので、「なぜ間違えたか」まで振り返れます。

### そのほか

- **電卓あり/なしの切り替え**：`js/config.js` の `calculator` を変えるだけで、暗算向けのキリのいい数字と、電卓向けの半端な数字を切り替えられます（SPIは受け方によって電卓の可否が違うため）。
- **スマホ優先のレイアウト**：幅320pxのスマホでも表やボタンがはみ出さないことを確認しています。
